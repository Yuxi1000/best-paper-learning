# Notice

This folder is a **personal writing-and-figure study corpus**.

- Source: author-posted arXiv PDFs of official Best / Outstanding papers.
- Stored: official abstracts, truncated section excerpts, extracted/rendered figures, and notes.
- Not stored as the deliverable: full paper text dumps.
- Use: learn rhetorical and visual patterns, then write original text and original figures.
- Do not: republish the corpus, paste exemplar sentences into a manuscript, or reuse another paper's images as if they were yours.
- Cite the original paper if a *scientific* idea (not a wording trick) influenced the work.

Rebuild with `../scripts/build_corpus.py` only when the user asks to refresh the list.
